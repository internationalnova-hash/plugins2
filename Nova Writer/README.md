# Nova Writer — AI Songwriting Companion

Open `app/index.html` in any modern browser. On first launch, enter your Anthropic API key (from console.anthropic.com). Your key is stored in localStorage only.

## Features (V1)
- Prompt-to-Song Blueprint (titles, concept, structure, hook ideas)
- Language control: English / Spanish / Spanglish / Bilingual / Latin Crossover
- Dialect flavor: Neutral Latin / Puerto Rican / Dominican / Mexican / Colombian / Spain
- Lyrics generator per section (Verse / Pre / Hook / Bridge)
- AI Tools: Make Hook Stronger, More Emotional, More Latin, Simplify, Add Spanglish, Rewrite Hook, Generate Alternate
- Chord progression grid with piano roll preview
- Export: Lyrics PDF, Chords MIDI, Melody MIDI
- Artist DNA & Reference Vocal — Phase 2
